Docu Builder is a bilingual editor for documents, slides, and pages. An agent edits each document through pure reducers and a single commit, scoped to a workspace.

Design and task cards live in [specs/001-docu-builder-ga/](specs/001-docu-builder-ga/). Read [IMPLEMENTER.md](specs/001-docu-builder-ga/IMPLEMENTER.md) before picking up a task.
